# Танковый хаос

Танчики для компании: каждый играет со своего телефона в браузере, Android и iPhone вместе.
Нужна только общая Wi-Fi сеть или раздача интернета с телефона.

## Как играть
1. Все открывают сайт игры.
2. Один нажимает **«Создать игру»**. Его телефон становится хостом и показывает код комнаты из 4 букв.
3. Остальные вводят код и жмут **«Войти»**.
4. Хост может добавить ботов и нажимает **«Начать бой»**.

Управление (по умолчанию «Простое»): левый стик двигает танк, башня смотрит по ходу движения,
кнопка 🔥 стреляет (держите — очередь), круглые кнопки — способности. В настройках можно включить
управление двумя стиками и переставить/изменить размер всех кнопок. На компьютере: WASD и мышь, способности — E и Q. Пули рикошетят и после рикошета могут попасть в своего же владельца.

## Режимы (настраивает хост в лобби)
- **Раунды** — без возрождений: раунд идёт, пока не останется один игрок или одна команда.
  Победитель получает очко, все проигравшие выбирают 1 из 3 карточек усиления.
  Через 45 секунд боя начинает сужаться зона — вне её танк теряет здоровье.
- **Фраги** — с возрождением, побеждает тот, кто первым наберёт нужное число уничтожений.
- **Состав**: каждый сам за себя или 2–4 команды. Игроки сами выбирают команду кнопкой «Сюда»,
  хост добавляет ботов в любую команду или выравнивает команды ботами одной кнопкой.
- Число раундов (или фрагов) до победы задаёт хост.
- Карта: одна из 6 арен (от 17×11 до 27×13 клеток) или «Случайная» — тогда каждый раунд новая.

## Карточки
42 карточки: усиления стрельбы и живучести, способности (Блинк, Невидимость, Стена, Мина — одна на танк)
и эволюции, которые выпадают только при наличии базовой карты (Дробовик → Пулемёт, Рикошет ×2 → Бильярд и т.д.).
Полный список с описаниями — в игре, кнопка «📖 Все карточки». В тренировке их можно выдавать себе кнопками + и −.

Совет: на iPhone «Поделиться → На экран „Домой“», на Android «Добавить на главный экран».
Так игра откроется во весь экран и будет загружаться без интернета.

## Как это устроено
- Чистый HTML/JS без сборки. 3D-отрисовка на Three.js, логика плоская (2.5D).
- Хост-телефон считает всю игру (`js/game.js`, боты в `js/bot.js`, карточки в `js/cards.js`)
  и 30 раз в секунду рассылает состояние.
- Связь между телефонами идёт через WebRTC (PeerJS). Интернет нужен на пару секунд для «рукопожатия»
  через публичный сервер PeerJS, дальше данные идут напрямую по локальной сети.
- Свой сервер рукопожатий можно указать в адресе: `?peer=host:port/path`.

## Запуск локально
```
python3 -m http.server 8000
```
и открыть `http://localhost:8000`.
