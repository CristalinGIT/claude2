# Танковый хаос

Танчики для компании: каждый играет со своего телефона в браузере, Android и iPhone вместе.
Нужна только общая Wi-Fi сеть или раздача интернета с телефона.

## Как играть
1. Все открывают сайт игры.
2. Один нажимает **«Создать игру»**. Его телефон становится хостом и показывает код комнаты из 4 букв.
3. Остальные вводят код и жмут **«Войти»**.
4. Хост может добавить ботов и нажимает **«Начать бой»**.

Управление: левый палец двигает танк, правый целится и стреляет. На компьютере: WASD и мышь.
Пули рикошетят один раз и после рикошета могут попасть в своего же владельца.

Совет: на iPhone «Поделиться → На экран „Домой“», на Android «Добавить на главный экран».
Так игра откроется во весь экран и будет загружаться без интернета.

## Как это устроено
- Чистый HTML/JS без сборки. 3D-отрисовка на Three.js, логика плоская (2.5D).
- Хост-телефон считает всю игру (`js/game.js`, боты в `js/bot.js`) и 30 раз в секунду рассылает состояние.
- Связь между телефонами идёт через WebRTC (PeerJS). Интернет нужен на пару секунд для «рукопожатия»
  через публичный сервер PeerJS, дальше данные идут напрямую по локальной сети.
- Свой сервер рукопожатий можно указать в адресе: `?peer=host:port/path`.

## Запуск локально
```
python3 -m http.server 8000
```
и открыть `http://localhost:8000`.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
